# Power BI Data Modeling Project

## 📌 Project Overview

This project demonstrates data modeling using Microsoft Power BI. It focuses on organizing data, understanding table relationships, and preparing a structured data model for data analysis and reporting.

The project is created using Power BI Desktop and saved in Power BI Project (PBIP) format for better project organization and source control.

## 🎯 Objectives

- Understand data modeling in Power BI.
- Organize data into structured tables.
- Establish relationships between tables.
- Build a semantic model for data analysis.
- Explore Power BI's data modeling capabilities.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power BI Project (PBIP)
- Data Modeling
- DAX (Data Analysis Expressions)

## 🚀 How to Open the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbip` file.
4. Allow Power BI Desktop to load the report and semantic model.
5. Explore the report and data model.
